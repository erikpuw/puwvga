# puwvga v1.0.3

## Tiếng Việt

### Sửa lỗi

- Sửa lỗi `RegisterTaskDefinition: Access is denied. (0x80070005)` khi bật **Tự áp màu khi đăng nhập và mở khóa máy** (Task Scheduler) hoặc khi cài đặt bằng `puwvga-setup` ở tài khoản người dùng chuẩn (không cần quyền Administrator).
- Gắn rõ tài khoản hiện tại (`USERDOMAIN\USERNAME`) cho cả `IPrincipal`, sự kiện đăng nhập (`ILogonTrigger`) và mở khóa màn hình (`ISessionStateChangeTrigger`) để tác vụ `puwvga_ApplyColor` được Windows Task Scheduler đăng ký và tự kích hoạt đúng sau mỗi lần khởi động lại máy hoặc mở khóa từ Sleep.

### Tệp phát hành

- `puwvga-v1.0.3-portable-x64.exe`: bản chạy trực tiếp không cần cài đặt.
- `puwvga-setup-v1.0.3-x64.exe`: bản cài đặt trên Windows 10/11 (64-bit).

### Lưu ý chữ ký số

Các tệp `.exe` trong phiên bản này chưa có chữ ký số (unsigned). Nếu Windows SmartScreen hiện cảnh báo ở lần chạy đầu tiên, chọn **More info** rồi nhấn **Run anyway**.

## English

### Bug fixes

- Fixed `RegisterTaskDefinition: Access is denied. (0x80070005)` when enabling **Auto-apply color on logon and unlock** (Task Scheduler) or installing with `puwvga-setup` under a standard non-administrator user account.
- Explicitly scoped `IPrincipal`, `ILogonTrigger`, and `ISessionStateChangeTrigger` to the current user (`USERDOMAIN\USERNAME`) so `puwvga_ApplyColor` registers cleanly in Windows Task Scheduler and runs automatically after every reboot or sleep unlock.

### Release assets

- `puwvga-v1.0.3-portable-x64.exe`: standalone portable binary.
- `puwvga-setup-v1.0.3-x64.exe`: Windows 10/11 (64-bit) installer.

### Code signing notice

Binaries in this release are currently unsigned. If Windows SmartScreen displays a warning on the first run, click **More info** and then **Run anyway**.
