# puwvga v1.0.1

## Tiếng Việt

### Thay đổi chính

- Thêm bộ biểu tượng (icon) chính thức cho ứng dụng, nhúng trực tiếp vào tệp `.exe` (hiển thị trên Explorer, Start Menu, Taskbar) và thanh tiêu đề cửa sổ.
- Bổ sung bản cài đặt Windows (`puwvga-setup-v1.0.1-x64.exe`) hỗ trợ tạo lối tắt Start Menu, Desktop và đăng ký gỡ cài đặt trong Windows Settings (Apps).
- Áp dụng trực tiếp Saturation và Hue xuống khối ma trận màu CSC 3x3 của driver Intel qua `ctlPixelTransformationSetConfig` (`ControlLib.dll`), kết hợp với Brightness, Contrast, Gamma qua LUT phần cứng và tự lưu vào `puwvga.presets.json`.
- Đọc và ghi trực tiếp cấu hình NVIDIA DRS (`nvdrsdb.bin`) và Digital Vibrance qua `nvapi64.dll`.
- Căn chỉnh lại giao diện Fluent theo bố cục 2 cột trên trang Tổng quan, thay thanh trượt mặc định bằng thanh trượt gọn hơn và gắn thanh cuộn sát mép ngoài cửa sổ.
- Bổ sung tùy chọn **Tự áp màu cùng Windows (Task Scheduler)** chạy ẩn `puwvga.exe --apply-only` khi đăng nhập hoặc mở khóa màn hình rồi thoát ngay lập tức, giữ màu ổn định qua các lần khởi động lại máy mà không chạy tiến trình nền.
- Khắc phục tình trạng trễ ngắn khi đóng cửa sổ ứng dụng bằng cách thoát ngay sau khi lưu cấu hình.
- Chuyển giấy phép dự án sang Apache License 2.0 và bổ sung tài liệu song ngữ (`README.md`, `README.en.md`).

### Tệp phát hành

- `puwvga-v1.0.1-portable-x64.exe`: bản chạy trực tiếp không cần cài đặt.
- `puwvga-setup-v1.0.1-x64.exe`: bản cài đặt trên Windows 10/11 (64-bit).

### Lưu ý chữ ký số

Các tệp `.exe` trong phiên bản này chưa có chữ ký số (unsigned). Nếu Windows SmartScreen hiện cảnh báo ở lần chạy đầu tiên, chọn **More info** rồi nhấn **Run anyway**.

## English

### Highlights

- Added the official application icon, embedded into both the Windows PE executable resource (Explorer, Start Menu, Taskbar) and the runtime window icon.
- Added a Windows installer (`puwvga-setup-v1.0.1-x64.exe`) with Start Menu and Desktop shortcuts plus Windows Settings (Apps) uninstall registration.
- Applied Intel Saturation and Hue directly to the hardware 3x3 CSC matrix block via `ctlPixelTransformationSetConfig` (`ControlLib.dll`), paired with hardware LUT controls for Brightness, Contrast, and Gamma and automatic preset saving in `puwvga.presets.json`.
- Added live NVIDIA DRS (`nvdrsdb.bin`) and Digital Vibrance read/write via `nvapi64.dll`.
- Refined the Fluent interface with a 2-column Dashboard layout, compact custom sliders, and an outer-edge scrollbar.
- Added **Auto-apply color with Windows (Task Scheduler)** (`puwvga.exe --apply-only` on logon and workstation unlock), restoring color settings after reboot or sleep and exiting immediately with zero background process.
- Fixed a brief teardown stall when closing the application window.
- Adopted the Apache License 2.0 and added bilingual documentation (`README.md` and `README.en.md`).

### Release assets

- `puwvga-v1.0.1-portable-x64.exe`: standalone portable binary.
- `puwvga-setup-v1.0.1-x64.exe`: Windows 10/11 (64-bit) installer.

### Code signing notice

Binaries in this release are currently unsigned. If Windows SmartScreen displays a warning on the first run, click **More info** and then **Run anyway**.
