# puwvga v1.0.2

## Tiếng Việt

### Thay đổi trong bản này

- Bổ sung chế độ chạy ẩn `puwvga.exe --apply-only` kết hợp Windows Task Scheduler (`puwvga_ApplyColor`): tự động nạp lại cấu hình màu từ `puwvga.presets.json` xuống driver (Gamma Ramp, Intel IGCL CSC 3x3, LACE và NVIDIA Digital Vibrance) khi đăng nhập Windows hoặc mở khóa màn hình sau Sleep, rồi thoát hẳn tiến trình (không chạy nền).
- Thêm nút gạt bật/tắt **Tự áp màu khi đăng nhập và mở khóa máy** trong mục Cài đặt và tùy chọn mặc định trong trình cài đặt `puwvga-setup` (tự động xóa tác vụ khi gỡ cài đặt).
- Sửa lỗi cửa sổ bị khựng nhẹ khi bấm nút đóng `X` bằng cách lưu cấu hình rồi kết thúc tiến trình ngay, tránh chờ giải phóng đồng bộ các DLL driver trên luồng giao diện.
- Bổ sung ảnh chụp thực tế giao diện Tiếng Việt và Tiếng Anh vào `README.md` và `README.en.md`.

### Tệp phát hành

- `puwvga-v1.0.2-portable-x64.exe`: bản chạy trực tiếp không cần cài đặt.
- `puwvga-setup-v1.0.2-x64.exe`: bản cài đặt trên Windows 10/11 (64-bit).

### Lưu ý chữ ký số

Các tệp `.exe` trong phiên bản này chưa có chữ ký số (unsigned). Nếu Windows SmartScreen hiện cảnh báo ở lần chạy đầu tiên, chọn **More info** rồi nhấn **Run anyway**.

## English

### Changes in this release

- Added headless `puwvga.exe --apply-only` mode with Windows Task Scheduler integration (`puwvga_ApplyColor`). It restores saved color settings from `puwvga.presets.json` (Gamma Ramp, Intel IGCL 3x3 CSC matrix, LACE, and NVIDIA Digital Vibrance) on Windows logon and workstation unlock, then exits immediately with no background process.
- Added an **Auto-apply color on logon and unlock** toggle in Settings and enabled it by default in `puwvga-setup` (automatically removed on uninstall).
- Fixed a brief freeze when closing the application window by flushing presets and exiting immediately instead of waiting on synchronous driver DLL teardown on the UI thread.
- Added real Vietnamese and English application screenshots to `README.md` and `README.en.md`.

### Release assets

- `puwvga-v1.0.2-portable-x64.exe`: standalone portable binary.
- `puwvga-setup-v1.0.2-x64.exe`: Windows 10/11 (64-bit) installer.

### Code signing notice

Binaries in this release are currently unsigned. If Windows SmartScreen displays a warning on the first run, click **More info** and then **Run anyway**.
